# ServiceCatalogueAIHelper

Веб-приложение для IT поддержки с AI-помощником, которое анализирует описание проблемы от пользователя и подбирает наиболее подходящую услугу из каталога.

## 📋 Описание

Приложение помогает пользователям быстро найти нужную IT-услугу из каталога, используя интеллектуальный AI-помощник. Пользователь может описать свою проблему естественным языком, и система автоматически подберёт наиболее подходящие услуги с указанием процента соответствия.

## 🚀 Функциональность

### AI-помощник
- **Анализ естественного языка**: Пользователь описывает проблему своими словами
- **Интеллектуальный подбор**: Система анализирует ключевые слова и подбирает подходящие услуги
- **Процент соответствия**: Показывает насколько точно услуга соответствует запросу
- **Быстрые подсказки**: Предлагает варианты услуг по мере ввода текста
- **Быстрые действия**: Кнопки для частых запросов (не работает ПК, нет интернета, забыл пароль)

### Каталог услуг
- **19 услуг** в 8 категориях
- **Поиск** по названию, описанию и ключевым словам
- **Фильтрация** по категориям
- **Детальная информация** о каждой услуге (описание, время решения, приоритет)

### Создание заявок
- Форма описания проблемы для выбранной услуги
- Генерация уникального номера заявки
- Подтверждение создания заявки с информацией о сроках

### Категории услуг
- 🖥️ **Оборудование** - запрос новых компьютеров, ремонт, периферия
- 💿 **Программное обеспечение** - установка, обновление, ошибки
- 🌐 **Сеть и связь** - интернет, VPN, подключения
- 🔑 **Доступ и учётные записи** - пароли, новые аккаунты, права доступа
- 📧 **Электронная почта** - отправка, получение, настройка
- 🛡️ **Безопасность** - фишинг, потеря устройств
- 📱 **Мобильные устройства** - запросы, синхронизация
- 🖨️ **Печать и сканирование** - настройка принтеров, неисправности

### Интерфейс
- **Адаптивный дизайн** - работает на десктопе, планшете и мобильных устройствах
- **Боковая панель** со статистикой и популярными запросами
- **Цветовая индикация** приоритетов услуг (критический, высокий, средний, низкий)
- **Анимации** и плавные переходы
- **Индикатор печати** AI-помощника

## 💡 Примеры использования

### Пример 1: Проблема с интернетом
**Пользователь**: "Не работает интернет на компьютере"

**AI-помощник**: Предложит услугу "Нет доступа в интернет" с высоким процентом соответствия

### Пример 2: Забытый пароль
**Пользователь**: "Забыл пароль от учётной записи"

**AI-помощник**: Предложит услугу "Сброс пароля" с указанием времени решения (30 минут - 2 часа)

### Пример 3: Установка программы
**Пользователь**: "Нужно установить Office"

**AI-помощник**: Предложит услугу "Установка программного обеспечения"

## 📊 Приоритеты услуг

- 🔴 **Критический** - немедленное реагирование (фишинг, потеря устройства)
- 🟠 **Высокий** - решение в течение нескольких часов (интернет, пароль, почта)
- 🟡 **Средний** - решение в течение 1-2 дней (новое оборудование, ПО)
- 🟢 **Низкий** - плановое выполнение (периферия, настройка)

## 🎯 Как это работает

1. **Ввод запроса**: Пользователь описывает проблему в чате или ищет в каталоге
2. **AI-анализ**: Система анализирует ключевые слова, названия и описания услуг
3. **Ранжирование**: Услуги сортируются по релевантности с расчётом процента соответствия
4. **Рекомендация**: AI показывает топ-5 наиболее подходящих услуг
5. **Создание заявки**: Пользователь выбирает услугу и создаёт заявку с описанием
